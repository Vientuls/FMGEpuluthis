# Answer corrections made in this app

When a printed answer key disagrees with the teacher's own handwritten tick/notes (or with the clinical facts), the corrected answer is
marked in the data and the explanation starts with "✔ Answer corrected to ...".

| Set | Question | Printed key | Corrected to | Why |
|---|---|---|---|---|
| Paediatrics T&D (40Q) | Q7 neonate, poor feeding + hypotonia, TSB 11 | A (observe, repeat TSB) | **D** (immediate double volume exchange transfusion) | Hypotonia + poor feeding = stage 1 acute bilirubin encephalopathy; DVET irrespective of TSB. Teacher's tick and note are on D. |
| OBG T&D (75Q) | Q72 HSG distal tubal dilatation, "tobacco-pouch" | A (tubal polyp) in the old file | **D** (tubal salpingitis) | The newer PDF key and the teacher's notes show D: distal tubal block = PID. |
